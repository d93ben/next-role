# Find and evaluate opportunities

1. Read target roles, location, work arrangement, compensation preferences, and the experience library. Ask only for missing constraints that materially affect the search.
2. Use the host's available web search or browser tools. Prefer a current employer careers page for verification. If browsing is absent, accept a pasted listing. If access requires sign-in or human interaction, follow the host's handoff process; do not bypass barriers.
3. For each promising role, verify title, employer, location, salary if actually disclosed, and application availability. Record what is unknown. Distinguish the employer's listing from aggregators and don't invent live openings.
4. Save the actual listing text, canonical URL, key requirements, specific experience matches, and genuine gaps with `job add`. The helper timestamps capture and rejects repeated canonical URLs. For missing URLs or distinct URLs for one posting, inspect existing jobs to avoid duplicates.
5. Start discovered opportunities as `saved`. Queue a job only when the user requests an application; preserve their request. User-provided URLs still require reading the listing before tailoring.
6. Explain the shortlist in terms of the person's priorities and evidence. Avoid numeric success predictions. Offer a useful next action, and save dates only when known.
7. Validate and rebuild. Return the specific opportunities saved and any limits in the search coverage. Never substitute demo listings for live research.
